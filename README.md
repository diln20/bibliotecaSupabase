# Supabase Academy

Guía educativa en un solo `index.html`, inspirada en la estructura pedagógica de la biblioteca Django del usuario.

## Contenido

- Fundamentos Web, HTTP, API y JSON
- Supabase y PostgreSQL
- Tablas, filas, columnas, tipos, claves, restricciones e índices
- SQL CRUD, filtros, JOIN, normalización y transacciones
- Data REST API / PostgREST
- `@supabase/supabase-js` v2
- CRUD completo desde JavaScript
- `fetch()` directo
- Auth, JWT y RLS
- Datos por usuario con `auth.uid()`
- Storage, Realtime y RPC
- Diagnóstico, pruebas y proyecto final

## Abrir

Abre `index.html` directamente en el navegador. Para publicar en GitHub Pages, basta con colocar el archivo como `index.html` en la rama configurada para Pages.

## Seguridad

Los ejemplos usan una clave publicable desde frontend. Nunca se debe exponer `service_role` ni claves secretas en el navegador.
